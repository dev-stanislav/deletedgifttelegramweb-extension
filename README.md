Deleted Gift Sender Web

Браузерный порт расширения Deleted Gift Sender (extraGram) для Telegram Web K.

Проект восстанавливает удаленные/скрытые Telegram Star Gifts в каталоге подарков путем внедрения известных ID подарков обратно в Telegram Web и загрузки их превью-стикеров из DeletedGiftsStickers.
